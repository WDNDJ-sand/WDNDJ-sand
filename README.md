## 🎮 游戏简介

**DELTA DEFENSE** 是一款以经典反恐游戏《彩虹六号》Delta Force小队为灵感的策略塔防游戏。你需要部署防御塔、操作枪手、指挥士兵小队，抵挡来自三个战术任务区的敌军入侵。

### 核心特性
- 🏗️ **6种防御系统**：脉冲箭塔、榴弹炮、冷冻塔、特斯拉线圈、枪塔、前进基地
- 🎯 **8种枪械装备**：从手枪到轨道炮，每种武器都有独特属性
- 💪 **15波战役**：从菜鸟拾荒者到BOSS级Boss敌人的渐进式挑战
- 🗺️ **3个任务区**：零号大坝 / 航天基地 / 潮汐监狱
- ⚔️ **4名精英操作员**：威龙、露娜、疾风、银翼，各具独特战术技能
- 💰 **Havoc货币系统**：击杀敌人获得货币，购买战术物资强化防线
- 🔧 **地形互动**：水域、高地、废墟、金属平台等环境因素影响战斗

## 🚀 快速开始

### 打开游戏
直接在浏览器中打开 `最新版——潮汐监狱.html` 文件即可开始游戏

**无需安装或网络连接** - 完全独立的HTML5应用

### 基础操作
| 快捷键 | 功能 |
|--------|------|
| `1-6` | 选择防御塔 |
| `Space` | 发动一波敌人 |
| `S` | 出售选中的塔 |
| `Esc` | 取消选中 |
| `Z` | 使用操作员技能 |
| `Q/E` | 快速使用Havoc道具 |
| `F` | 撤离逃生点 |
| `Tab` | 返回地图选择 |
